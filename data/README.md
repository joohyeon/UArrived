# data/ — reviewable content, not code

- `tasks/`     deterministic task definitions and applicability rules (who a task applies to, prerequisites)
- `resources/` official links, each with **publisher** and **review date**
- `sample/`    the sample incoming student and marketplace listings used by demos and tests

Changes to `tasks/` and `resources/` need the content/safety owner's approval (CODEOWNERS).
